# 候選題目包檔案格式

輸出檔名：`候選題目包-<簡稱>.md`，存在使用者當下工作目錄。

## 章節結構

1. **題目敘述**：因果／比較／差異句型的完整題目句。
2. **研究範圍裁切**：時間・空間・群體，各自的具體範圍與選擇理由。
3. **外部否決風險快篩結果**：兩題的回答與判定（通過／待查），待查項目要點出來。
4. **三重評估摘要**：
   - 創新縫隙：初步判斷＋依據。
   - 文獻空白：WebSearch 查核紀錄（搜尋關鍵詞、查到什麼、判斷依據），標明這只是輕量查核，不是正式 gap 分析。
   - 實務可行：資料取得管道、範圍合理性的初步判斷。
5. **待教授確認事項**：條列使用者下一步該去跟教授確認的具體問題，尤其是快篩階段標記為「待查」的項目。

## 收尾語氣

短句祝賀＋提醒這是候選版本，不是定案，建議接下來：（1）帶著這份候選題目包去跟教授確認；（2）開始針對確定的方向讀文獻建立概念，或找研究缺口。不宣稱題目已經通過驗證。
